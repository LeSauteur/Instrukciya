# Справочник франшизы Домиан

Статический сайт для руководителей и команд франшизных офисов.

- `index.html` — полный справочник: правила, регистрация, контакты, группы MAX, документы и офисы.
- `contacts.html` — самостоятельная страница только с контактами для отправки агентам. В ней нет меню или ссылок на основной справочник. Это отдельная ссылка, а не ограничение доступа к публичному сайту.
- `assets/groups.json` — 43 группы MAX, предоставленные собственником.
- `assets/offices.json` — снимок действующих офисов из officeip от 18.11.2026; без архивных записей и закрытых офисов Баева, Князева и Котовской.
- `documents/` — анкета и два оффера. В оффере агентов ставка исправлена на подтверждённые собственником 2,5% с оборота сделки; в оффере администратора мессенджер заменён на MAX.

## Локальный просмотр

Запустите любой статический HTTP-сервер из корня репозитория, например `python -m http.server 4178`. Откройте `http://localhost:4178/`; страница для агентов — `http://localhost:4178/contacts.html`.

## Проверка

```powershell
npm ci
npm run qa
```

Дополнительно проверьте в браузере desktop и mobile: навигацию, общий поиск, фильтры групп и офисов, чек-лист, копирование, скачивание документов, отдельную страницу контактов, отсутствие горизонтального переполнения и ошибок консоли.

Сайт не собирает данные кандидатов. Чек-лист работает в памяти открытой страницы. Для обновления содержания редактируйте HTML, для обновления каталогов — соответствующие JSON-файлы. После изменения офисов сверяйтесь с актуальным officeip.

Публикация — только по прямому поручению через origin, отдельную ветку, PR и зелёный QA. Настройки существующего GitHub Pages сохранены.
