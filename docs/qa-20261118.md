# Обновление справочника франшизы 18 ноября 2026

Подготовлена новая версия полного справочника и самостоятельная страница `contacts.html` для агентов. Публикация не выполнялась.

## Содержание

- 12 разделов, общий поиск, навигация по постоянным якорям, мобильное меню.
- 43 ссылки MAX из задания: 2 группы франшизы, 35 групп новостроек, 4 группы АН Домиан и 2 ипотечные группы.
- Правила регистрации: документы до 16:00, регистрация и фиксация с 16:00 до 18:00, перенос неполного комплекта на следующий день, полный чек-лист, копируемая шапка и реквизиты проверки СБ.
- Поползина Екатерина принимает оплату обучения и документы на регистрацию. Контакты Арлашиной и Деменкова удалены. Добавлены Лилекина, Барлаухян и Плешаков; у Тимура указана только фото- и видеосъёмка.
- 68 действующих офисов из актуального officeip: 59 франшизных и 9 офисов Павла Орлова. Архивные офисы не включены. По поручению собственника удалены Баев / Добровольского, Князев / Суворовский и Котовская / Эксперт; такие же удаления подготовлены отдельно в officeip.
- Анкета 2026 сохранена без изменений. В оффере агентов ставка заменена на подтверждённые пользователем **2,5% с оборота сделки агента**, в оффере администратора Ватсап заменён на MAX. Из оффера агентов удалён пустой завершающий абзац, создававший лишнюю страницу.
- На `contacts.html` представлены 19 контактов, поиск по именам, ролям и телефонам. Ссылки страницы ведут только на телефонные номера; основная инструкция, группы, офисы и документы не загружаются. По решению пользователя отдельная ссылка достаточна, авторизация не добавлялась.

## Проверки

- `npm ci` — успешно. Внешних npm-зависимостей нет.
- `npm run qa` — 8 из 8 тестов успешно: внутренние ссылки и ID, отсутствие старых сотрудников и WhatsApp, полнота правил регистрации, офисы, группы MAX, самостоятельность контактов, документы и синтаксис JS.
- `git diff --check` — без замечаний.
- В браузере проверены desktop 1280 px и mobile 390 / 320 px. Все 13 экранов основного справочника проверены при ширине 320 px, горизонтального переполнения нет.
- Проверены общий поиск, фильтр ипотеки (2 группы), отсутствие результатов, поиск офисов Шахт (2 офиса), мобильное меню, чек-лист и реальное содержимое буфера обмена после копирования шапки и карты.
- На отдельной странице поиск «съемка» возвращает Тимура, поиск по части телефона «928 774» — Екатерину. Проверено отсутствие переполнения при ширине 320 / 390 px и отсутствие переходов к инструкции.
- Ошибок и предупреждений консоли на проверенных страницах не обнаружено.
- HTTP-проверка главной, контактов, двух каталогов и трёх документов: статус 200 и побайтовое совпадение с файлами проекта.
- XML обоих DOCX корректен. Ставка и MAX проверены в XML и визуально. Штатный `render_docx.py` недоступен из-за отсутствия LibreOffice в Windows; выполнен экспорт через отдельный экземпляр native Word, затем рендер Poppler и просмотр всех страниц PNG. Итог: оффер агентов — 1 страница, администратора — 2 страницы. Пользовательские исходники в «Загрузках» не изменялись.
- В локальном officeip поиск Баева, Князева и Котовской возвращает 0 результатов. Осталось 77 записей: 68 действующих и 9 архивных; оба офиса Шахт сохранены.

## Источники и пределы проверки

Правки основаны на задании и уточнениях пользователя, исходной инструкции, опубликованном officeip и трёх предоставленных файлах из «Загрузок». Остальные внутренние правила и ссылки сохранены из исходной инструкции; их актуальность владельцы отделов отдельно не подтверждали. Приглашения MAX сверены с предоставленными URL; возможность вступления в закрытые группы не проверялась. Страница контактов не ограничивает доступ к публичной инструкции — это согласованная отдельная ссылка.

Настройки GitHub Pages, origin и deployment remote не изменялись. Push, PR и развёртывание не выполнялись.
